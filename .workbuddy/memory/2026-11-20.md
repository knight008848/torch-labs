**阻塞项 1（真 bug）**：`probe_gpu_compute` 把 `torch_module.cuda.is_available()` 放在 `try` 外。
`probe_cuda:107` 早就为同一调用包了 try（注释："driver mismatch, missing libcuda" 会抛）。
后果：换机器重建时驱动不匹配 → 整脚本 traceback，后面 headless/skeleton 段全看不见。
修：移进 try，返回 `Probe(FAIL, "not run - no usable GPU")` / `raised ...`。

**阻塞项 2（真 bug）**：`probe_matplotlib_backend()` 的结果只 print，未进 `failures` 列表。
强制其返回 FAIL 时报告打印 `[fail]` 但 `RETURN CODE = 0` —— **校验器自己有一次没响**。
修：存成 `backend_probe` 变量，`if status == FAIL: failures.append(...)`。
